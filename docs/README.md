# GitHub Pages source

This folder is the GitHub Pages source (Settings, Pages, branch `main`, folder `/docs`).

- `index.html`, `assets/`, `site-config.js`: the project landing page. Edit `site-config.js` to set the project video (`VIDEO_URL`).
- `downloads/`: copies of the paper and slide PDFs that the project landing page links to. Refresh them from `paper/main.pdf`, `presentation/main.pdf` and `presentation/main-notes.pdf` whenever those change.
- `evalboard/`: the static, scrubbed Evalboard trace explorer. Generated by `scripts/build_pages.sh`. The published snapshot, including `data/`, is tracked.
